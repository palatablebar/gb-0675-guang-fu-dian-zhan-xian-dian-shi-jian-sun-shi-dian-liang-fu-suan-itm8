# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

## 补证工作台

截数后到达的补传记录按“基准批 + 补证轮次”叠加复算，基准批本身始终不变。页面 `GET /supplement`，提交 `POST /api/supplement`，参数 `base_run_id`、`csv_text`、`void`（对象）或 `void_text`（每行“编号,原因”）。

- 可用损失=所有已能算出的片段之和；正式损失=其中位于已核清时段的片段之和；暂定损失=已算出但所在时段未核清的部分。未定片段不参与任何求和，也不填0。
- 受影响时段=与隔离记录、裁定剔除、补证采纳或补证锁定记录重叠的连续片段；时段内仍有未定片段或有隔离/锁定记录时为未核清，其中的取值只列为暂定。
- 补证锁定：落在基准批已确定为正式时段的补证行不并入复算，只登记原因 `LOCKED_WINDOW`；编号与已有记录重复且取值不同登记 `ID_CONFLICT`；同编号同取值登记 `DUPLICATE_NOOP` 不重复采信。
- 裁定剔除：`void` 中的编号退出本次复算，原值原行进入裁定台账并计入行守恒；裁定不得指向已确定的正式片段（触发 `LOCKED_VIOLATION`）。
- 同一补证与裁定重跑生成同一批号，正式值按段位锁定，不新增、不覆盖、不改变。补传齐备且受影响时段全部核清后 `status` 为“完整”，四账守恒且无限电事件被隔离时可归档。
